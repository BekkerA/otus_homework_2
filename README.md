otus_homework_2
Домашнее задание 2 OTUS "Рефакторинг ДЗ из первого модуля"
Проект разделен на 3 папки:
1. model - в папке 3 скрипта:
contact.py - информация с классом контакта, с разными функциями ввода, вывода в класс.
storage.py - класс для работы с JSON на файловой системы в части ввода/вывода и проверок.
phone_book.py - класс телефонного справочника, для инициализации которого необходимо считать информацию из JSON через storage.py и "элементами" которого являются класс из contact.py.
2. view в папке единственный скрипт console_view.py, в котором собраны функции, вызов которых приведет к чтению/записи из консоли.
3. controller - в папке единственный скрипт phone_book_controller.py, который управляет вызовом функций для работы с консолью и наполнением классов из модели.
В файле exceptions.py собраны кастомные исключения для обработки всевозможных ошибок.
